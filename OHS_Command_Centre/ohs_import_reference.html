1 · JSON Object Schema

Each metric in the import file is one JSON object. Only id and value are required. Omit optional fields or leave them as empty strings.

Field Required Type Allowed Values Description
id Required Integer 1 – 62 Metric ID matching the dashboard framework. Must match exactly — unrecognised IDs are ignored.
value Required String "3" / "4.2" / "87%" / "$12,400" Current period result. Always a string — include units, percentages, or currency symbols as part of the value. Blank values are skipped.
target Optional String "<5" / "≥95%" / "0" Performance target or benchmark. Displayed alongside the value in the badge. Include comparison operator.
trend Optional String "up" / "down" / "flat" Movement since last reporting period. Renders as ↑ (teal) / ↓ (red) / → (grey) in the badge. Lowercase only.
note Optional String "Q1 2025" / "YTD" / "Rolling 12m" Period label or contextual note. Displayed in small text inside the badge. 
// Minimal record — required fields only
{ "id": 1, "value": "3" }

// Full record — all fields populated
{
  "id": 1,
  "value": "3",
  "target": "<5",
  "trend": "down",
  "note": "Q1 2025"
}

// Array of multiple metrics
[
  { "id": 1,  "value": "3",   "target": "<5",     "trend": "down", "note": "Q1 2025" },
  { "id": 2,  "value": "0",   "target": "0",       "trend": "flat"                    },
  { "id": 18, "value": "4.2", "target": "<6.0",   "trend": "up",  "note": "Rolling 12m" }
]
You do not need to populate all 62 metrics. Import only the metrics you have data for. The dashboard renders imported values as amber badges on populated rows and leaves unpopulated rows unchanged.

3 · Converting a CSV to JSON

Three options below — choose the one that fits your environment. Option A requires no software. Options B and C are one-line commands.

CSV column order: Your CSV must have these column headers exactly: id,value,target,trend,note. You can omit target, trend, and note columns entirely if not used — the converter will leave them blank.
A Microsoft Excel or Google Sheets — no software required

Build your data in a spreadsheet. Column A = id, B = value, C = target, D = trend, E = note. Row 1 is headers, data from Row 2.

In an empty cell, paste this formula. Adjust the range (A2:E63) to match your data rows.

// Excel / Google Sheets formula — paste in any empty cell
// Produces a JSON array you can copy directly into the dashboard import field

="["&TEXTJOIN(",",TRUE,
  IF(B2:B63<>"",
    "{"&
    """id"":"&A2:A63&","&
    """value"":"""&B2:B63&""","&
    """target"":"""&C2:C63&""","&
    """trend"":"""&D2:D63&""","&
    """note"":"""&E2:E63&"""}"
  ,""))&"]"
Google Sheets: Enter with Ctrl+Shift+Enter (array formula). Excel: Enter with Ctrl+Shift+Enter on older versions; on Excel 365 enter normally. Copy the cell output, paste into the Import Data modal.
B Python — one command, no packages required

Save your CSV as ohs-metrics.csv. Run this from the same folder.

id,value,target,trend,note 1,3,<5,down,Q1 2025 2,0,0,flat,Q1 2025 5,14,,up,Q1 2025 18,4.2,<6.0,down,Rolling 12m 19,1.4,<2.0,down,Rolling 12m
# Save as convert.py and run: python convert.py
# Input:  ohs-metrics.csv
# Output: ohs-metrics.json  (ready to import into the dashboard)

import csv, json

with open("ohs-metrics.csv", newline="", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

output = []
for r in rows:
    if not r.get("id") or not r.get("value"):
        continue                          # skip empty rows
    record = {
        "id":     int(r["id"]),
        "value":  r["value"].strip(),
    }
    if r.get("target", "").strip():
        record["target"] = r["target"].strip()
    if r.get("trend", "").strip():
        record["trend"]  = r["trend"].strip().lower()
    if r.get("note", "").strip():
        record["note"]   = r["note"].strip()
    output.append(record)

with open("ohs-metrics.json", "w", encoding="utf-8") as f:
    json.dump(output, f, indent=2)

print(f"Converted {len(output)} records → ohs-metrics.json")
C Node.js — if Python is not available

Requires Node.js. Run from the folder containing your CSV.

// Save as convert.js and run: node convert.js
// Input:  ohs-metrics.csv
// Output: ohs-metrics.json

const fs = require("fs");

const lines  = fs.readFileSync("ohs-metrics.csv", "utf8").trim().split("\n");
const header = lines[0].split(",").map(h => h.trim());

const output = lines.slice(1).map(line => {
  const vals = line.split(",").map(v => v.trim());
  const row  = Object.fromEntries(header.map((h, i) => [h, vals[i] ?? ""]));
  if (!row.id || !row.value) return null;
  const rec = { id: parseInt(row.id), value: row.value };
  if (row.target) rec.target = row.target;
  if (row.trend)  rec.trend  = row.trend.toLowerCase();
  if (row.note)   rec.note   = row.note;
  return rec;
}).filter(Boolean);

fs.writeFileSync("ohs-metrics.json", JSON.stringify(output, null, 2));
console.log(`Converted ${output.length} records → ohs-metrics.json`);
D After conversion — importing into the dashboard

Once you have the ohs-metrics.json file:

StepAction
1Open the dashboard in your browser. Click Import Data in the top-right.
2Either drag the JSON file into the drop zone, or click to browse and select it.
3The JSON content loads into the text area. Review it, then click Apply.
4Amber badges appear on each populated metric row showing value, target, trend, and note.
5To export with data visible, click Export PDF. The print dialog opens — select Save as PDF.
6To reset, click Clear data in the amber banner at the top of the dashboard.
Tip: Download the pre-built template by clicking Template JSON in the dashboard header. It contains all 62 metric IDs and names pre-filled — open in a text editor, add your values, save, and import. No CSV conversion needed if you populate the template directly.
