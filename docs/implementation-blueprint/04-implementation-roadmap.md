## Sequencing Notes

- **R0 is not optional scaffolding** — Ontology must exist and be seeded before R1, because every classification field in Risk Register is an ontology FK ([03-postgresql-schema.sql](../knowledge-graph/03-postgresql-schema.sql)). Attempting R1 without R0 complete reproduces V1's original defect inside the new platform.
- **R6/R7 complexity (XL)** is not schedule padding — these are the two modules with no V1 precedent at all (architecture §7 gap analysis), meaning no existing logic to port, only new build against the design docs.
- The roadmap does not assign calendar durations — Phase 2.1 is planning, not estimation; durations belong to a project-management artefact outside this document set, populated once a delivery team and velocity exist.
